## 2. ローカル開発クイックスタート

### 前提

- Node.js + npm
- PostgreSQL（開発: `localhost:5432/headless_cms`）
- ポート: **3000** = CMS、**3001** = Preview デモ（任意）

### 初回 / DB

```bash
cp .env.example .env
brew services start postgresql@17   # または既存 Postgres
npx prisma generate
npx prisma migrate deploy
npx tsx prisma/seed.ts            # 末尾で static-export も実行
```

### 日常

```bash
npm run dev                        # http://localhost:3000
cd examples/preview && python3 -m http.server 3001   # API プレビュー用
npm test
npm run build                      # dev 停止後
npm run export:preview             # 全コンテンツ HTML 一括出力
```

`.env` 推奨: `FRONTEND_BASE_URL=http://localhost:3001`

**ログイン（デモ）**: `admin@example.com` / `admin1234`

## 4. プレビュー・公開の 3 経路

| 経路 | 用途 | 更新タイミング |
|------|------|----------------|
| **配信 API（JSON）** | 案件本番フロント | 公開直後（CSR なら再 fetch で最新） |
| **API プレビュー** | `examples/preview` + `:3001` fetch | 保存後にページ再読み込み |
| **静的 HTML** | `examples/preview/generated/{draft\|published}/` | 保存/公開/非公開フックで自動上書き |

本番案件の配信は **JSON API のみ**（ヘッドレス原則）。静的 HTML はデモ専用。
